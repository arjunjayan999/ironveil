## Explicitly Out of Scope

The following features are intentionally **not** part of this project:

- Real sensor hardware integration - all telemetry is generated by the Sensor Simulator.
- Processing or storing real-world customer security data - the platform operates entirely on synthetic events.
- Billing, subscription management, or SaaS administration.
- Mobile applications - the project is designed as a responsive web application.
